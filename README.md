# GenAI Assignment #1 — Image Restoration & Face-to-Sketch Generation

Four generative AI systems integrated into a single web application:

1. **Universal Restoration** — Denoising autoencoder handling clean, salt-and-pepper, blur, and occlusion
2. **Hard-Routed Restoration** — Corruption classifier → specialist autoencoders
3. **Soft Mixture-of-Experts Restoration** — Differentiable gating network + weighted expert blend
4. **Face-to-Sketch Generator** — Style-conditioned conditional GAN (FS2K dataset)

## Quick Start

```bash
# 1. Clone and enter the repo
git clone <repo-url> && cd GenAI-A1

# 2. Download models (or train from scratch — see below)
python scripts/download_models.py

# 3. Start the application
docker compose up --build

# 4. Open in browser
# http://localhost:3000
```

## Training from Scratch

```bash
# Install dependencies
pip install -r requirements.txt

# Download datasets
python scripts/download_datasets.py

# Generate deterministic manifests
python scripts/generate_manifests.py

# Train Task 1 (Universal Autoencoder)
python src/training/train_task1.py

# Train Task 2 (Hard-Routing Classifier & Specialists)
python src/training/train_task2_classifier.py
python src/training/train_task2_specialists_hpo.py
python src/training/train_task2_specialists.py

# Train Task 3 (Soft Mixture-of-Experts)
python src/training/train_task3_moe_hpo.py
python src/training/train_task3_moe.py

# Train Task 4 (Face-to-Sketch GAN)
python src/training/train_task4_optuna.py
python src/training/train_task4_final.py

# Export all trained models to ONNX
python src/export/export_task1.py
python src/export/export_task2.py
python src/export/export_task3.py
python src/export/export_task4.py
```

## Application Workspaces

The browser application features 4 distinct workspaces:
- **Pipeline 01:** Upload images, apply configurable runtime corruptions (Type & Severity), and restore them.
- **Pipeline 02:** View predicted corruption probabilities and the deterministically selected hard-routing expert.
- **Pipeline 03:** View the dynamic blending weights (softmax distribution) generated by the Soft MoE gating network.
- **Pipeline 04:** Capture a live photograph using your **Webcam** (or upload a file), select a sketch style condition, and synthesize the paired sketch.
- **Downloading:** All workspaces support direct downloading of the restored/generated outputs.
